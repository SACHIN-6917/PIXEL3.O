## 🔥 PIXELO 3.O — National Level Technical Symposium

**Organized by:**  
Department of Computer Science and Engineering  
**Adhiparasakthi Engineering College**  
*In Association With Computer Society of India (CSI) – Kanchipuram Chapter*

---

### 🌟 Overview
A modern, cinematic, high-performance web application built for the **PIXELO 3.O** National Level Technical Symposium. Inspired by the vibrant Phoenix theme (fire, resilience, re-birth, technology).

### 🚀 Key Features
- **Cinematic Phoenix Hero**: Looping high-definition video background layer with fiery typography.
- **Dynamic 4-Step Registration Wizard**:
  - Step 1: Participant & College Details with real-time validation.
  - Step 2: Technical Event Selection (PaperQuest [Team of 4] or AI FilmForge [Solo]).
  - Step 3: Non-Technical Event Selection (Checkmate [Solo] or Mine Relay [Team of 4]).
  - Step 4: Live summary review with instant ID generation and Supabase integration.
- **Dedicated Multi-Page Routing**:
  - `/` — Landing & Hero Preview
  - `/about` — About Symposium & Detailed Event Rules
  - `/registration` — Interactive Registration Flow
  - `/agenda` — Animated Schedule Timeline
  - `/venues` — Campus & Event Hall Directions
  - `/student-coordinators` — Student Leadership & Contact Directory
  - `/staff-coordinators` — Faculty Advisory Panel
- **Instant Connect**:
  - WhatsApp Community integration
  - Click-to-call mobile dials for coordinators
  - Direct links to college & symposium social media handles

### 🛠️ Tech Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Phoenix Color Tokens
- **Icons & Motion**: Lucide React + Framer Motion
- **Backend / Database**: Supabase PostgreSQL (`pixelo_registrations` table)
